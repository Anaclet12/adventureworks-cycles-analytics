## How to Generate `analytics_ecosystem.png`

The image was generated in conversation with Claude. To regenerate or modify:

1. Open the saved version (PNG download from the conversation).
2. Save as `docs/images/analytics_ecosystem.png` in this folder.
3. Commit and push — the top-level `README.md` will automatically render it.

If the image is missing, the README will show a broken-image icon in that spot. Add the file to fix it.
